# NCR-013 — Adaptive attention policies from retained proof catalogues

NCR-012 qualifies all outcome intersections for a catalogue of up to six offers and packets of at most two bits. This round reuses those actual proofs: no new ANF substitution or overlay construction is needed to compile a conditional policy. It combines VGI's complementarity and VL-I's strict evidence finalization with IFS anticipatory retention. See [NCR-012](NCR-012.md) for pinned source references and the uniform hidden-member prior, fallback/geometry cost definition and per-refinement budgets.

## Exact Bellman construction

A history h is the sorted tuple of distinct observed (offer,bit) pairs. The proof catalogue supplies the nonempty or empty persistent overlay F_h, its count N_h, target-positive count Y_h and summed address-embedding visits V_h. Let L_h be the terminal numerator:

    L_h = N_h*(fallback*[0<Y_h<N_h] + node_price*overlay_nodes)
          + visit_price*address_queries*V_h.

For each unobserved offer a, the two children partition F_h. The optimal conditional numerator over policies of remaining depth is

    B(h) = min(L_h, min_a(N_h*c_a + B(h+a=0) + B(h+a=1))).

A zero-count branch stops at zero; at the declared horizon all branches stop. The root expected cost is B(empty)/N_empty. Induction on the remaining horizon proves optimality: the policy either stops or pays the chosen acquisition price for every state in the current fibre, then solves two independent conditional subproblems. Ties stop first and then use lexical offer name. Every fixed packet of length <= horizon is a permitted adaptive policy (ignore the earlier bit when choosing the next offer), so adaptive minimum cannot exceed the best NCR-012 packet under this identical *terminal* geometry charge. Intermediate overlay lookup/retention, actual sensing, fallback acquisition, full source reconstruction and planning are not charged in this objective. The fallback is the stipulated directly measured target, not an automatically executed operation.

The compiler independently checks the catalogue before computing bottom-up scores. A separate checker enumerates stop/second alternatives and first alternatives without calling the compiler, audits every decision and reuses NCR-012's independent outcome checks. Both currently pay full catalogue audit; the Runtime pays that audit once at admission and reuses the immutable branch proofs across sessions. The finite table has at most 73 histories. The runtime validates chronological decisions against the table and rejects contradictions/out-of-order observations, returns the exact original-parent overlay, and never guesses a mixed target. Only the two-probe horizon and declared offer set are optimized; increasing the horizon requires a different bounded preparation contract.

## Native APIs

    from navigable_compute.intention_fibre import construct_fibre
    from navigable_compute.fibre_attention import Offer, Prices, plan_attention
    from navigable_compute.adaptive_attention import compile_policy, Runtime
    from navigable_compute.adaptive_attention_verify import verify_policy

    f = construct_fibre(128, ())
    offers = (Offer("a",(1,),1),Offer("b",(2,),1))
    c = plan_attention(f,offers,(1,2,3),Prices(10),max_packet=2)
    p = compile_policy(c)
    assert verify_policy(c,p)
    r = Runtime(c,p)
    s = r.begin("source-epoch","unique-hidden-member-context")
    s = r.advance(s,"a",1)
    assert r.view(s).terminal and r.view(s).inferred == 1

The OR task costs 1.5 per hidden member vs 2 for the best fixed packet under uniform prior. The mux task ab XOR c XOR ac (= b if a else c) chooses a first, then b or c. With equal unit costs and fallback 10 it costs 2 vs 7 for the best fixed packet (two fixed probes leave half the members ambiguous; however a singleton can cost 1+10, and no probe 10). Tests use source enumeration on small systems to check every deterministic depth-two strategy and realized session costs, plus geometry prices, refusals and forged decision controls. The demo reports paid catalogue preparation, compilation with audit, runtime admission and 1,000 warm local sessions separately.

## Actual VGI adapter

Study [VL-I TDL-003's implementation](https://github.com/Kier73/VL-I/blob/00fd4026dc3c35bc130d2d09ab9d88b354616d7b/src/vli/cost_aware_refinement.py) and use the real [VGI evidence ledger](https://github.com/Kier73/Virtual-Ground-Interpreter/blob/ae3f949b7d0b2aaa42236bc7cc37e9857384b174/virtual_ground_interpreter/vgi/evidence.py), not a duplicate finalization system. The optional adapter binds each requested ANF, policy identity, source epoch, session ID and exact ordered prior trace into a SHA-256 observation context. The receiver owns expected strict policy, allowed sources, quorum and trusted ledger provenance. Only VGI's finalized AUTHORIZED one-bit self-transition advances the mathematical session. Reconstruct the immutable ledger using its own from_dict checks, then replay the policy transition; the returned receipt records before/after session, context, policy/ledger/decision digests. A changed session, old step, wrong policy, pending/missing/conflicting claims and changed receipt are refused.

A separate CI workflow installs the pinned real VGI package and exercises native ChannelMessage, EncounterProvenance, TransportFrameReceipt, exchange and finalization across both mux branches and negative controls. These are synthetic receiver-attributed observations, not live remote sensors or mTLS authentication. Raw Runtime.advance remains available for declared mathematical fixtures; a receiver must expose only its qualified adapter, keep unique session IDs and trusted current session, and enforce E-CPU transport admission separately. Session/receipt records are local objects, not a portable durable journal or replay-prevention authority. Replaying the same context is deterministic; rolling back the receiver state is outside this stateless adapter.
