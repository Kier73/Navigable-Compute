# NCI-001 — From required invariants to a transformation space

**Status:** Implemented and locally tested, 20 November 2026. Python >=3.10, no third-party runtime dependencies. **This lane does not receive a program, action effects, transition table, sample trajectory, or precomputed ranking.** Its input is a finite mathematical description of what a future processor must respect.

## The experiment

**Can an observer state the invariants of a desired system, derive its space of valid transition laws, and navigate directly to a concrete machine that satisfies them?**

NCP-001 synthesizes a controller from *declared action effects*. NCI-001 instead synthesizes the **transition semantics themselves** from a geometry and invariants. It does not supplant NCP's adversarial-effect construction; these are separate authority and modeling situations.

An `InvariantDescription` contains:

- **Geometry:** a finite set `S` of distinct integer lattice coordinates, with Manhattan metric `d(s,t)`.
- **Symmetry:** one exact bijection `g:S→S` that must be an isometry (`d(g(s),g(t))=d(s,t)`). The generator induces a finite cyclic group action.
- **Conserved observable:** a supplied label `L(s)` that must satisfy `L(g(s))=L(s)` and be preserved by any constructed transition.
- **Safety:** forbidden states `U`, with `g(U)=U`.
- **Intention:** goal set `G`, with `g(G)=G`; nonempty allowed initial set `I`.
- **Locality:** maximum transition displacement `R` in the same metric. This is a *mathematical restriction*, not a measured physical limit.

**Not supplied:** next-state values or action names; known training traces; a transition-ranking function; an allowable program grammar; a cost model for a physical host.

## The constructed mathematical space

An admitted processor is a partial deterministic map `T:S⇀S`, defined on the certified goal-reachable subset, with these invariants:

1. **Absorption:** `T(s)=s` for every goal `s∈G`.
2. **Conservation:** `L(T(s))=L(s)`.
3. **Safety:** `T(s)∉U`.
4. **Locality:** `1≤d(s,T(s))≤R` for nonterminal states.
5. **Equivariance:** `T(g(s))=g(T(s))` for every state where `T` is defined.
6. **Progress:** each admitted nonterminal state strictly decreases the **derived** shortest goal-distance rank.

If a state cannot reach the goal within the derived relation, its transition is explicitly `-1` (unqualified), and the constructor refuses if any declared initial state is among these. The result is the family of **shortest-progress, symmetry-equivariant partial processors**. It is not the whole family of every eventually converging or arbitrary transition system.

### Group-orbit construction

The symmetry splits the finite Ground into cycles. Let `r` represent a cycle of size `m`. A choice `T(r)=t` determines `T(g^k(r))=g^k(t)` for the entire source cycle.

The choice is well-defined exactly when `g^m(t)=t`. For a single cyclic permutation this is equivalent to:

`size(orbit(t))` divides `size(orbit(r))`.

This is the key global constraint that cannot be reduced to naive per-state target selection. The compiler generates all geometric, label-preserving, safe, and symmetry-compatible targets **for representatives only**, and obtains a quotient graph on the cycles. It then computes shortest distances to goal cycles by reverse graph traversal. Each representative can choose any target of rank exactly one less than its own. If `c_i` is the number of such choices on nonterminal orbit `i`, the number of distinct admitted processors is exactly:

`N = product(c_i)`.

One integer architecture coordinate `0 ≤ k < N` selects one law by mixed-radix decomposition. This is **navigation among computed possible systems**, not fast-forwarding a predefined program. Each chosen law has a guaranteed goal-hitting horizon bounded by its maximum initial-state rank; beyond that coordinate, its goal observations remain constant.

The correctness argument consists of: (a) source orbit stabilizer compatibility, (b) isometry and label invariance preserve admissibility under the group action, (c) strict descent of nonnegative integer rank guarantees termination, (d) the goal's identity mapping is equivariant, and (e) independent representative choices cannot conflict because source orbits partition the state set.

### Existence and obstruction

Not every apparently navigable geometric intention admits a symmetry-preserving transition. On a `3×3` square with 90° rotation, the center is fixed by the rotation, but the four corners form a four-state cycle. A request to move the center to any corner is incompatible with equivariance, **even when the maximum geometric displacement permits it**.

NCI-001 refuses the construction and emits an exact **closed-trap obstruction**: a union of whole state orbits that intersects the allowed initial set, excludes all goals, and has no legal symmetry-compatible exit. The independent verifier checks this closure by reconstructing candidate geometric edges directly, without trusting a producer's claimed rank or digest. A closed trap rules out the declared family; it is not an impossibility theorem for other metrics, omitted symmetries, or a physical implementation.

## Verification contract

The checker in `invariant_verify.py` does **not** call the producer's graph construction or shortest-distance routine. Instead it:

- derives symmetry cycles independently;
- checks label, safety, locality, divisibility and Bellman rank optimality directly for every state;
- independently reconstructs the eligible representative choice sets;
- recomputes the complete instantiated transition table from the chosen coordinate;
- checks law counts, worst-case depth, scope and canonical digest;
- verifies closed-trap obstructions without trusting a rank certificate.

A separate **256-map exhaustive oracle** enumerates all deterministic transition tables in a 4-state example and compares them to the two maps produced by the symbolic orbit constructor. Altered semantic certificates fail even if their SHA-256 value is recomputed. `invariant_wire.py` uses the established NCW-001 strict canonical JSON envelope, verifies the trusted invariant description on receipt, rejects duplicate keys and tampering, and does not claim signature or external provenance.

## Complexity and what is not established

For `n` explicitly listed states, validating metric symmetry and deriving geometric candidates requires worst-case `O(n²)` comparisons. Rank construction over orbit adjacency and architecture selection then operate on these computed finite structures. A product of *independent* components can be constructed without expanding its Cartesian global state space, but this does not resolve coupled or undecidable instances.

The current implementation does not infer geometry or conservation laws from natural-language input; the caller declares those invariants. It does not discover a unique optimal objective among competing metrics or build unbounded or continuous transition manifolds. Its semantics are deterministic and locally state-observed; it does not support adversarial physical outcomes in this lane. It does not prove arbitrary P/NP speedups, a proof of RH, or physical availability of a host capable of implementing the selected mathematical law. An E-CPU host must separately qualify any requested effect, and VGI must retain the exact observation/authority scope.
