# NCR-022 — Coalescent computational intelligence fleet

Extends NCR-021's independently verified reflective interpreter. Inspired by
[VL-64 source-pinned observer fleets](https://github.com/Kier73/VL-64/blob/46d58dd3f445de4e1f898e0d9f9c1e41d68b59d2/docs/SOURCE_PINNED_BEHAVIOR_FLEET.md),
[E-CPU self-organizing fabric](https://github.com/Kier73/E-CPU/blob/df75e8dee43c48c93bdca73637dada95c7d53f81/docs/SELF_ORGANIZING_FEDERATED_GROUNDS_SAB006.md),
[IFS CAG-001](https://github.com/Kier73/In-Formation-Space/tree/ccf7dfb88a52c458ee9dd00e26ffbaecf5b2af9c/experiments/convergent-ground-fabric)
and [VL-I PFI-002](https://github.com/Kier73/VL-I/blob/00fd4026dc3c35bc130d2d09ab9d88b354616d7b/docs/PROBLEM_FORMED_FABRIC_PFI002.md).
The current adapter uses NCR's own proof kernel, not imported VL-64/E-CPU
network runtime. It applies CAG's grow-only inventory idea to algebraic proofs.

## Semantics

All workers reconstruct the same independently admitted nonempty source Ground
F. The receiver pins the original Vocabulary identity and ordered base catalogue
digest. A contribution is a canonical JSON description containing these pins,
an advisory actor/task label, a vanishing polynomial g, and exact original
rule/multiplier indices. The receiver checks:

    g = XOR_j x^m_j r_i_j

via the existing independent NCR-015 verifier. Since each base r_i vanishes
on F, every admitted g vanishes on F. No received answer, actor label, majority
vote or digest supplies mathematical authority. Distinct valid proof variants
for the same relation are retained as provenance, but only one rule enters the
materialized vocabulary. Source identity includes receiver-defined context.
Different Grounds cannot silently merge source-specific facts.

For a valid bounded packet set S, merge is set union by canonical content hash,
with collision refusal. Union is associative, commutative and idempotent.
Materialize sorts distinct new relations and selects the first certificate
in canonical hash order. All certificates refer only to immutable base rule
indices, so arrival order cannot change their meaning. Consequently identical
valid inventories yield identical materialized rule order and deterministic
rewrite behavior. Partial inventories may leave an intention unresolved.
Batch ingest validates each new packet and the union capacity before publishing;
bad batches do not alter accepted inventory. A refusal on capacity does not
guarantee convergence across replicas that cannot hold the complete set.
No distributed consensus, mutation of committed external effects, or Byzantine
liveness is asserted. Labels are untrusted; a digest is not a signature.
Caps: 256 packets, 64KiB each, 8MB aggregate, 64 distinct learned rows and
existing proof work caps. Snapshot requires independently supplied base;
restore rechecks every proof, not a cold target DAG.

## Experiments

The shared 128-bit source contains n disjoint majority-three equations, with
2^(128-n) members. Each worker receives one assigned source equation; alternating
workers use actual NCR-017 transversal activation or a targeted NCR-016 product
construction. Both generate product proofs referencing only original source
rules. The new collective intention is an XOR of all n first-pair vanishing
factors multiplied by separate spectator coordinates. It is not one of the
worker targets. An individual contribution cannot resolve it with the admitted
rewrite grammar, but the complete union can resolve it by verified rewriting.
A cold exact comparison verifies the same result. This is a workload chosen
to expose complementary structure, not proof that a single sufficiently
resourced interpreter could not solve it. All workers receive full source
descriptions; assigned task scope is not a security isolation boundary.

Local fleet benchmark: 32 task invocations (8 complementary primary tasks,
24 redundant), 8 spawn-process slots. Counts actual distinct process IDs
rather than claiming one physical host per task. It records worker computation
and process pool wall time, wire bytes, materialization/reaudit, collective
query time and cold exact comparison. No claim of speedup after coordination.
Tests exercise independent spawned processes, duplicates, random arrival orders,
complementary replica anti-entropy, cross-context refusal, tampered proof,
atomic invalid batch, recovery and unresolved spectator-bit control.

Dedicated hosted experiment: four separately scheduled producer jobs publish
proof-only artifacts to the GitHub artifact service; a fifth job downloads all
four and independently verifies convergence in opposite orders and realizes
the new intention. Same administrative trust domain, not a physical peer-to-peer
network or remote attestation. The separate workflows run on Linux and Windows
for general conformance; the artifact path uses Ubuntu. Neither benchmark
requires live external sensing, shared model weights or a continuously running
central intelligence. No timing statistics pooled across clock actors; cost
policy remains local as NCR-020 requires.
