# NCR-014 — Intent-neutral observation memory and native recovery cuts

Continuation of [NCR-013](NCR-013.md). This experiment asks whether the evidence acquired for one intention can qualify another intention without re-observing the hidden source, and whether that evidence survives loss of an observer process.

Related research studied, not copied: [IFS PGI-001](https://github.com/Kier73/In-Formation-Space/blob/3707544223f33c54b6bf94511beebc2805001bb4/experiments/ground-intelligence/README.md) retains qualified mathematical views; [PGI-002](https://github.com/Kier73/In-Formation-Space/blob/3707544223f33c54b6bf94511beebc2805001bb4/experiments/ground-intelligence/PGI-002.md) retains checked callable semantics while learned proposal order is advisory; [VL-64 active action Grounds](https://github.com/Kier73/VL-64/blob/46d58dd3f445de4e1f898e0d9f9c1e41d68b59d2/docs/ACTIVE_ACTION_GROUNDS.md) separate current observation evidence from modeled actions; [VL-I TIME-005A](https://github.com/Kier73/VL-I/blob/00fd4026dc3c35bc130d2d09ab9d88b354616d7b/docs/TIME_005_SIGNED_PROCESS_CONTINUITY.md) separates publisher observation and observer process recovery. The experiment directly imports actual VGI and E-CPU APIs, especially [SAB-007](https://github.com/Kier73/E-CPU/blob/df75e8dee43c48c93bdca73637dada95c7d53f81/mailcpu/federated_ground_continuity.py), immutable content storage and recovery lineage.

## Mathematical continuity

One receiver-declared epoch and unique context denote ONE fixed hidden initial member x in an admitted parent F. Original attention policy acquires a finite history h of ANF observations p_i(x)=b_i. The evidence-qualified domain is

    F_h = F intersect all {p_i=b_i}.

For any subsequent Boolean intention q, compute y=|F_h intersect {q=1}| by NCR-011 persistent intersection of the original parent with the evidence equations and target. Independently check the new residual edges and counts. If y=0 then q(x)=0 for every admitted member; if y=|F_h| then q(x)=1; otherwise return unresolved (no fabricated bit). The current F_h overlay and its ordinal injection into F remain unchanged. An exact previously acquired polynomial bit or original target proof is reused without further residual formation. Other targets pay fresh refinement and independent verification; no claim of zero computation. The source must be the same hidden member and coordinate convention; a changed environment begins a new receiver-defined epoch/context. No general cross-time environmental invariance or additional sensor acquisition for the new intention is implied.

## Memory and recovery API

Memory(runtime,epoch,context,allowed_sources,quorum) starts a locally admitted NCR-013 session. append(ledger) calls the actual VGI adapter under the receiver-configured strict policy. Store canonical immutable records of each finalized VGI ledger, its decision/context/policy digest and chronological trace. snapshot() returns deterministic JSON bytes. restore(runtime,epoch,context,allowed_sources,quorum,payload) requires independently supplied authority and runtime; reconstruct each ledger through VGI's own validation, replay only mathematical admission and compare canonical bytes. The packet omits the full proof catalogue; the receiver must already possess or reconstitute an independently admitted original runtime. The maximum depth stays two. This is a portable evidence packet, not a self-contained executable seed.

seal(memory,coordinator,storage,previous=...) writes exact canonical bytes to E-CPU AtomicGroundEvidenceStore, then uses RecoveryStateManifest and RecoveryLineageCoordinator.seal. A first generation must contain exactly one observation; each successor must extend the exact currently authoritative evidence bytes by one event. Recheck source/context/authority before sealing. Native quorum verification fences stale generations, a minority cannot certify a cut, and changed prefix is rejected even under a valid next-generation request. recover(...) checks native live quorum, content digest and VGI reconstruction. Recovery does not call any sensor or rerun a measurement. A changed or missing artifact is refused. No duplicate quorum or signature algorithm is implemented.

## Executed experiment contract

The integration fixture starts a 128-bit XOR intention, acquires a=1, seals generation 1 under three native durable authority journals. A separate OS worker reopens the quorum and immutable artifact, reconstructs the admitted runtime, obtains a synthetic finalized b=0 observation, seals generation 2 and calls os._exit(73) before acknowledging semantic success. A new receiver opens the same journals, checks high-water and the supplied manifest locator, restores the exact evidence, then resolves OR=1 and AND=0 with no additional acquisition. A third unobserved bit remains unresolved with exactly half the refined source states satisfying it. Additional tests reject minority commit, changed prefix, stale root, mutated artifact, changed context and forged record fields.

The fixture uses synthetic receiver-attributed VGI channel evidence and actual native E-CPU local quorum files. This is OS-process continuity on one CI machine, not independent physical host loss, mTLS sensing, source signatures or a distributed artifact replication service. The manifest locator is retained separately; the test exits after writing that locator, not at every possible crash boundary. The source runtime is reconstructed on recovery and the cost is not free. E-CPU native authority protects the accepted root, not truth of an external sensor. The caller owns membership, artifact availability, unique session identity and measurement transport authority. Arbitrary Python mutation in the same trusted process is not a supported threat model.
