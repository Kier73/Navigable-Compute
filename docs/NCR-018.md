# NCR-018 — Intention-shaped proof, without constructing its entire vocabulary

A follow-up discovered through [NCR-017](NCR-017.md). The learned positive-transversal skill can generate a catalogue of derived rules, but an intention that already specifies a coordinate assignment needs only its particular proof. The underlying identity extends to signed cubes through ordinary Boolean cofactor substitution.

For disjoint coordinate masks A and B (ones and zeros), define the factored indicator

    g(x) = product_{i in A} x_i * product_{j in B} (1 XOR x_j).

For a known vanishing equation r, if the cofactor r|_{A=1,B=0}=1, every assignment in the cube has r=1. It follows that the cube is disjoint from the admitted Ground. Equivalently g*r=g, hence g=0 on that Ground. The positive-transversal motif is the A=empty case where every nonconstant term is killed. Signed restriction generalizes that supplied algebraic template; the system does not invent arbitrary operator syntax. In particular, the source need not itself have a constant-one term: setting some variables to one may create that constant, and distinct projected monomials may cancel.

prove_cube(skill,v,ones,zeros) searches already admitted equation rules, restricting each term without expanding g. Drop terms intersecting B, remove A from the others, XOR equal projected masks. A constant-one cofactor yields a compact CubeProof binding the receiving Ground identity, rule index, rule digest and exact intention masks. The independent verifier projects onto free coordinates and counts parity via Counter, not the producer's toggling procedure. Both perform at most linear term visits per inspected equation (integer and set/hash costs additional). The producer's total term-search budget is 1e6. The proof records the selected rule's term count rather than total failed search work. No learned fact is added to the vocabulary. If no single admitted equation suffices return UNKNOWN; a conjunction of equations may still rule out the cube, as explicitly tested. Budget refusal raises FibreBudget, not UNKNOWN from completed search.

The skill must be admitted by NCR-017, and the source must be an independently admitted receiver-local Vocabulary. Proof soundness depends on these existing source rules, not on the learned examples. No authentication is inferred from hashes. Proof packet is canonical JSON for storage/measurement; verification currently operates on the typed receipt. No physical observations are acquired. No portable proof readmission protocol or quorum commit is introduced here.

## Exponential catalogue control

On a 128-bit source, set r=1 XOR sum_{i=0}^{47} x_{2i}x_{2i+1}. Its 48 disjoint two-variable supports have exactly 2^48 inclusion-minimal hitting sets, each of size 48. Explicitly enumerating that vocabulary or expanding one all-zero cube into ANF terms would require 2^48 entries/terms respectively. The former catalogue is outside NCR-017 budgets and arity. Instead choose one zero coordinate in each pair as a factored signed intention, optionally set a spectator bit to one, and inspect the 49 terms of r. No exponential expansion occurs. Exact state count is ((4^48-2^48)/2)*2^32, since each pair product has three zero assignments and one one assignment. This structured family is not arbitrary SAT.

The demo tests 32 distinct requested cubes and 32 controls leaving a pair unassigned, compares them to exact native coordinate intersections and independent verification, and reports training, source admission, proof and cold comparison times separately. Tests also include signed nonconstant source, 160 small randomized cube oracle attempts, forged/changed intention/context controls, budget refusal, and joint-entailment UNKNOWN.

    python -m unittest discover -s tests -p test_intention_cofactor.py -v
    python intention_cofactor_demo.py

The operation can also be applied without learning using a standard cofactor solver. This experiment studies how a verified skill and a typed intention guide selection of a mathematical procedure, not a claim that prior training is required to implement cofactors.
