# NCR-010 — Inverse temporal intention fibres

Builds on [NCR-007](NCR-007.md), [NCR-008](NCR-008.md) and [NCR-009](NCR-009.md). Instead of merely computing the observer at a logical time for a supplied initial state, construct the exact set of initial states satisfying several masked observations at independently specified logical horizons.

For each goal g=(w,n,m,v), the required relation is O(T_w^n(x)) & m = v. NCR-009's terminal compiler supplies canonical ANFs F_g without constructing the full future-observer basis. For every requested output bit, impose F_g,i(x) XOR v_i = 0. The inverse fibre is the conjunction of all such equations. A raw ANF entrypoint also accepts stipulated Boolean equations directly.

## Addressing a solution rather than searching for one

Split the most significant remaining source variable x_k. Every ANF has the unique decomposition p=a XOR x_k*b. The two residual systems use a and a XOR b respectively. Identical canonical residual systems at the same remaining width share one node. A constant-one equation yields the empty fibre, while the empty residual at width zero denotes the one empty assignment. Empty residuals at higher widths retain both branches so that unconstrained bits contribute their full multiplicity.

For each node R, C(R)=C(R|x_k=0)+C(R|x_k=1). These child sets are disjoint and exhaustive, establishing exact count by induction. To unrank j, follow the zero branch if j<C(low), otherwise subtract C(low), set x_k=1 and follow the one branch. Rank reverses that calculation. Hence addresses [0,C(root)) biject with satisfying source states in increasing numeric order. The source width bounds warm navigation to at most 128 node visits, irrespective of the numerical address. An unsatisfiable request has count zero and no valid address.

The independent verifier starts at the supplied equations, uses parity counting rather than the producer's set toggling, checks every residual identity, strictly descending node references, count recurrence, unique residual identity, reachability, and the declared work count. Temporal verification revalidates the NCR-007 source and recompiles the terminal ANFs with the independent substitution engine. Call rank/unrank only on an independently checked immutable certificate; this is a mathematical certificate, not a signed external receipt.

## Reproduce

    python -m unittest discover -s tests -p "test_intention_fibre.py" -v
    python intention_fibre_demo.py

The first fixture has 128 variables and all 127 adjacent constraints x_i*x_(i+1)=0. It is a single connected incidence component, so NCR-008's disjoint-support enumeration would have a 128-bit local component. The path has a compact residual graph: once its highest remaining variable has been selected, only its adjacent constraint can affect the next choice. There are at most two viable residual forms per layer. Its count is Fibonacci F_130 (F_0=0, F_1=1), not 2^128. This is a nonlinear but tractable coupled structure, not a hard SAT benchmark.

The second fixture uses the original 128-bit NCR-007 native source. At one action the observation is (x1*x2,x64); after the certified drain it is (0,x64). Requiring outputs (1,1) and (0,1) fixes exactly three source bits to one, hence 2^125 admissible initial states. A conflicting observation gives zero. A horizon 10^100+173 is reduced through the independently checked drain law, rather than replayed.

    from nonlinear_koopman_demo import nonlinear_family
    from navigable_compute.intention_fibre import Goal, construct_temporal_fibre
    from navigable_compute.intention_fibre_verify import verify_temporal_fibre
    source = nonlinear_family()
    goals = (Goal((0,), 1, 3, 3), Goal((0,), 10**100+173, 3, 2))
    certificate = construct_temporal_fibre(source, goals)
    assert verify_temporal_fibre(source, goals, certificate)
    state = certificate.fibre.unrank(10**30)
    assert certificate.fibre.rank(state) == 10**30

The demo charges cold formation, independent verification and warm address navigation separately. Residual work counts one per node plus twice the number of equations and monomials inspected, not all CPU operations. The fixed variable order is an explicit design choice; poor order or dense coupled equations can yield exponentially many residuals. The compiler refuses incomplete graphs at explicit node and work budgets, and the temporal pullback retains NCR-009's existing polynomial budgets. The benchmark makes no universal complexity or P=NP claim.
