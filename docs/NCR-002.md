# NCR-002 — Self-interpretation as a constructive invariant

**Status:** executable finite research experiment, November 20, 2026.

## The question

Can the demand *"the task-processor must interpret an encoded description of its own evaluator"* constrain the construction of a processor architecture, rather than merely being checked after a researcher writes an interpreter?

NCR-001 supplied a seven-primitive reflective language and a hand-constructed interpreter. NCR-002 **retains the finite language's specified meaning** but does not supply the finished evaluator or fixed source encoding as inputs. It searches a declared, finite library of semantic primitive constructions, chooses a minimum-size physical primitive basis, constructs the complete evaluator source from the language's five syntax laws, derives a Ground-specific five-symbol source encoding, and refuses to admit the result unless an independent operational engine can interpret the evaluator *interpreting its own encoded source*.

This is a **bounded constructive specification**, not proof that arbitrary intentions spontaneously generate universal languages, that all primitives are reducible, or that machine code runs without a host.

## Exact semantic constructions

For qualified operands, the minimum seed within the supplied recipe space is:

`at`, `cons`, `eq`, `rest`.

The remaining required operations are generated as expressions of these seeds:

```
first(sequence)      = at(sequence, 0)
empty(sequence)      = eq(sequence, ())
task(opcode, state)   = at(at(qualified_task_table, opcode), state)
```

`task` is not a primitive of the **constructed reflective host**. The task's table comes from the independent NCS-001 algebra. Input well-typedness is essential: these equalities do not promise identical exception behavior on malformed input. Candidate basis minimization enumerates all subsets of the seven declared operations, accepting a subset only if **every** target operation has an admitted semantic recipe; the independent checker does its own enumeration and refuses claimed nonminimal designs.

The constructed evaluator implements five source forms (`lit`, `arg`, `if`, `prim`, `call`) and six helper functions (`lookup`, `evaluate_list`, `perform`, `evaluate`, `invoke`, `run`). The code is a normal source-language AST, not host-side `eval` or a privileged interpreter opcode. Its own source is represented as an input program under the constructed codebook.

## An addressable architecture representation space

Every Ground has **120 distinct 5-symbol encodings** because five source tags admit `5!` permutations. A source-ground SHA-256 digest determines the canonical ordering, and a **factoradic unranking** of integer `0 ≤ k < 120` chooses one exact alternative representation without generating all 120 first. These are *representational gauges*, **not** 120 semantically distinct processors and not a computational speedup. The compiler constructs and verifies the evaluator for the chosen coordinate.

For two differently generated Grounds (3×3 and 5×5), even the same architecture coordinate can map to different syntax codebooks, while interpreting the same five semantic forms. All source data remains content-addressed to the task Ground, architectural choice, and executing word.

## Self-interpretation obligation

For source program `P`, constructed evaluator `E`, source encoding `Q_G`, and input `x`, test:

```
host(P, x) = y
host(E, (Q_G(P), 'main', x, Ground)) = y
host(E, (Q_G(E), 'run', (Q_G(P), 'main', x, Ground), Ground)) = y
```

The third expression actually **interprets the interpreter source** through the very semantic evaluator being tested. Both physical executors enforce the selected **four-primitive** host basis. Each stage has an explicit expression-step cost. A separately implemented continuation-stack machine replays these executions and checks the receipt, without calling the producer's recursive evaluator.

An independent checker also evaluates source constructs and primitive operations on a bounded typed input corpus, checks every primitive seed and declared macro recipe, validates the source alphabet, and rejects tampered sources, forged seed sets, incorrect source digests or invalid results even if hashes are recalculated.

**Scope qualification:** This is stronger evidence than merely inspecting the source AST or producing a quine, but still finite operational checking. It is not a machine-checked general theorem that every program terminates or is interpreted correctly. Additional proof-kernel obligations and distinct host processes remain future work.

## Reproduction

Requires Python 3.11+ standard library only.

```sh
python -m unittest discover -s tests -v
python reflective_architecture_demo.py > ncr002-evidence.json
```

The deterministic JSON records the source Ground, selected primitive basis, derived operations, representation coordinate, the three interpretation depths, their costs and content identities.

## Distinguishing failures

- Remove the `at` primitive from the permitted seed pool. No design exists **within this recipe grammar**; the constructor refuses rather than importing `task` or arbitrary Python.
- Replace the `run` body with a forged constant and recompute the artifact digest. The independent evaluator refuses because observed semantics are wrong.
- Alter the declared codebook coordinate, primitive seed, Ground digest or output work count and recompute the wire checksum. Independent reconstruction refuses.
- Try negative, Boolean, out-of-range representation coordinates or over-budget reflection. The contract refuses.
- Encode a source expression outside the five declared syntax forms. Refuse; don't invent semantics.

## Research interpretation and next experiment

The **constructed capability** is a small compiler that derives *some* representation/evaluator decisions from semantic invariants. The **remaining external design** is the mathematical language, finite recipe grammar, task input and realizer. The next frontier is to derive candidate *language constructors* from the task's required observables and proof obligations, then use full formal semantics or a kernel to qualify universal self-interpretation within a typed terminating fragment. The behavior of arbitrary recursive programs is not decidable in general.
