# NCR-009 — Computational complexity as a navigable representation property

Builds on [NCR-007](NCR-007.md), [NCR-008](NCR-008.md), [E-CPU ITR-001](https://github.com/Kier73/E-CPU/blob/main/docs/INTENTION_TO_VERIFIED_REALIZATION_ITR001.md) and [IFS CIG-023](https://github.com/Kier73/In-Formation-Space/blob/main/experiments/pnp-ground-navigation/cut_intention/CIG-023.md). ITR-001 charges discovery and verification; CIG-023 selects proof architectures for a requested witness rather than requiring all global feasible times. Here the source family is the original declared NCR-007 nonlinear Boolean law, not a discovered external system.

## Five executable representations

For source action word w, repetition n and observer O, each alternative realizes O(T_w^n(x)). The source candidate retains the final source vector. Feature retains NCR-007's exact future-observation vector q. Packed retains NCR-008's exact mixed-radix encoding of q. Terminal compiles only the requested O composed with T_w^n. Terminal deliberately has no continuation service. Source, feature and packed admit future actions from their retained coordinates without the original x. A fifth candidate, stationary, is eligible only after the certified drain. It uses NCR-008 to encode the exact image of the terminal observer itself; since all further source actions fix the drained state, every future observation equals that terminal output. Its transition on the packed coordinate is identity.

NCR-007's ranked dependency invariant implies that after H = 1 + max(tiers) actions (including H=0), active bits are zero and protected bits are unchanged, for every action word. Exploit that identity in all four general candidates when |w|n >= H; source masks protected coordinates directly, feature and packed project the protected state directly, and terminal drops monomials containing active bits. Before H, use source stepping, feature stepping or backwards pullback of the exact ANF. The independent terminal compiler uses NCR-007's separate parity substitution implementation. The local result verifier independently replays at most H original actions using set-based ANF evaluation and compares both output and retained coordinates.

This strong baseline matters: logarithmic powering is not optimal for this draining source family. No general time-navigation claim follows.

## Minimal coordinate observation

For a fixed terminal intention, let F(x) be the vector of canonical multilinear GF(2) polynomials produced by reverse substitution. Let S be the union of variables in nonzero ANF monomials. S is sufficient. It is also necessary for a uniform nonadaptive raw-coordinate acquisition contract on the full Boolean cube: if a variable occurs, its Boolean derivative is a nonzero multilinear polynomial and has a nonzero evaluation, so a pair of source states differing only in that variable has different output. No fixed raw-coordinate subset omitting it can distinguish both. This does not claim optimal adaptive probes, linear combinations, remote measurements, or minimum description size.

On the original 128-bit fixture the one-action goal w=(0,), n=1 has F=(x1*x2,x64), thus exactly three essential bits. Far beyond the drain horizon, F=(0,x64), exactly one essential bit. The full future-observer feature rank is ten and the realized image has 192 states requiring eight bits. The terminal two-bit result does not represent an arbitrary future processor before the drain. After the drain the stationary candidate has two realizable outputs, requiring exactly one bit for every future observation. The local independent verifier still receives the entire source state, so producer read-mask counts are not end-to-end traffic measurements.

## Cost and selection

For each qualified candidate c, retain S_c = measured setup and independent qualification time, W_c = median of verified per-query latency over a disjoint calibration corpus, B_c = retained fixed-width coordinate bits, R_c = raw producer read-mask cardinality. For a declared number N of subsequent queries and nonnegative scenario prices lambda, mu (ns-equivalent units per retained/read bit):

    J_c(N) = N (W_c + lambda B_c + mu R_c)

Choose the least J among candidates satisfying continuation and capacity constraints. For cold standalone counterfactuals add S_c. These prices are explicitly hypothetical, not measured transfer costs. The planner prices each offered retained-coordinate service as specified; a caller that discards all coordinates should set lambda=0. Setup, calibration of every alternative and selection are paid by the actual portfolio. The benchmark separately reports exploration wall time plus selection plus held-out realization; it does not pretend the cold counterfactual winner can be discovered for free. Candidate setup times share feature construction and are not summed twice in the portfolio preparation ledger. Calibration wall time, medians and held-out measurements are empirical and not deterministic guarantees. The selection explores five specified candidates (one conditional), not all possible algorithms.

## Reproduction

```sh
python -m unittest discover -s tests -p 'test_complexity_navigation.py' -v
python complexity_navigation_demo.py
```

The benchmark uses nine calibration and twelve disjoint held-out source states for four logical horizons, reports candidate preparation and verification costs, and evaluates six selection scenarios. Deterministic profile tests verify cost switches and capacity refusal independent of CPU timing. Before the drain, a continuation-only 8-bit storage contract admits the packed mode and excludes both the 10-bit feature and 128-bit source representation; a seven-bit ceiling refuses among those offered future-complete modes (not a proof about every possible endpoint-specific continuation). After the drain a one-bit ceiling selects the stationary mode. A zero-bit ceiling refuses because both protected bit values are possible. Terminal support tests exhibit necessity witnesses and compare states agreeing only on the selected coordinates.

## Independent endpoint discovery

A local independent Python oracle ran Moore partition refinement on the nine-variable first-lane/protected-bit source (512 assignments), then counted distinct future-observer classes at the endpoint of every action word of length 0 through 4. All words of each length had the same class count:

| Actions | Endpoint classes | Minimum fixed-width bits |
| ---: | ---: | ---: |
| 0 | 192 | 8 |
| 1 | 48 | 6 |
| 2 | 12 | 4 |
| 3 | 4 | 2 |
| 4 | 2 | 1 |

This enumerates the small independent observer cone as a validation oracle, not the full 128-bit source. The executable test retains the calculation. A new research possibility is time-indexed packed image certificates of q composed with the action history, with migration to the next image on each action. The current portfolio implements the universal eight-bit image and the stationary one-bit endpoint; intermediate 6/4/2-bit online migration is the next construction. In general, endpoint images need not be invariant under arbitrary next actions, so the successor coordinate must bind the successor image, not silently reuse the previous codebook.
