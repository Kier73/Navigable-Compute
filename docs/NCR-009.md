# NCR-009 — Computational complexity as a navigable representation property

Builds on [NCR-007](NCR-007.md), [NCR-008](NCR-008.md), [E-CPU ITR-001](https://github.com/Kier73/E-CPU/blob/main/docs/INTENTION_TO_VERIFIED_REALIZATION_ITR001.md) and [IFS CIG-023](https://github.com/Kier73/In-Formation-Space/blob/main/experiments/pnp-ground-navigation/cut_intention/CIG-023.md). ITR-001 charges discovery and verification; CIG-023 selects proof architectures for a requested witness rather than requiring all global feasible times. Here the source family is the original declared NCR-007 nonlinear Boolean law, not a discovered external system.

## Four executable representations

For source action word w, repetition n and observer O, each alternative realizes O(T_w^n(x)). The source candidate retains the final source vector. Feature retains NCR-007's exact future-observation vector q. Packed retains NCR-008's exact mixed-radix encoding of q. Terminal compiles only the requested O composed with T_w^n. Terminal deliberately has no continuation service. The other three admit future actions from their retained coordinates without the original x.

NCR-007's ranked dependency invariant implies that after H = 1 + max(tiers) actions (including H=0), active bits are zero and protected bits are unchanged, for every action word. Exploit that identity in all four candidates when |w|n >= H; source masks protected coordinates directly, feature and packed project the protected state directly, and terminal drops monomials containing active bits. Before H, use source stepping, feature stepping or backwards pullback of the exact ANF. The independent terminal compiler uses NCR-007's separate parity substitution implementation. The local result verifier independently replays at most H original actions using set-based ANF evaluation and compares both output and retained coordinates.

This strong baseline matters: logarithmic powering is not optimal for this draining source family. No general time-navigation claim follows.

## Minimal coordinate observation

For a fixed terminal intention, let F(x) be the vector of canonical multilinear GF(2) polynomials produced by reverse substitution. Let S be the union of variables in nonzero ANF monomials. S is sufficient. It is also necessary for a uniform nonadaptive raw-coordinate acquisition contract on the full Boolean cube: if a variable occurs, its Boolean derivative is a nonzero multilinear polynomial and has a nonzero evaluation, so a pair of source states differing only in that variable has different output. No fixed raw-coordinate subset omitting it can distinguish both. This does not claim optimal adaptive probes, linear combinations, remote measurements, or minimum description size.

On the original 128-bit fixture the one-action goal w=(0,), n=1 has F=(x1*x2,x64), thus exactly three essential bits. Far beyond the drain horizon, F=(0,x64), exactly one essential bit. The full future-observer feature rank is ten and the realized image has 192 states requiring eight bits. The terminal two-bit result does not represent an arbitrary future processor before the drain. The local independent verifier still receives the entire source state, so producer read-mask counts are not end-to-end traffic measurements.

## Cost and selection

For each qualified candidate c, retain S_c = measured setup and independent qualification time, W_c = median of verified per-query latency over a disjoint calibration corpus, B_c = retained fixed-width coordinate bits, R_c = raw producer read-mask cardinality. For a declared number N of subsequent queries and nonnegative scenario prices lambda, mu (ns-equivalent units per retained/read bit):

    J_c(N) = N (W_c + lambda B_c + mu R_c)

Choose the least J among candidates satisfying continuation and capacity constraints. For cold standalone counterfactuals add S_c. These prices are explicitly hypothetical, not measured transfer costs. The planner prices each offered retained-coordinate service as specified; a caller that discards all coordinates should set lambda=0. Setup, calibration of every alternative and selection are paid by the actual portfolio. The benchmark separately reports exploration wall time plus selection plus held-out realization; it does not pretend the cold counterfactual winner can be discovered for free. Candidate setup times share feature construction and are not summed twice in the portfolio preparation ledger. Calibration wall time, medians and held-out measurements are empirical and not deterministic guarantees. The selection explores four specified candidates, not all possible algorithms.

## Reproduction

```sh
python -m unittest discover -s tests -p 'test_complexity_navigation.py' -v
python complexity_navigation_demo.py
```

The benchmark uses nine calibration and twelve disjoint held-out source states for four logical horizons, reports candidate preparation and verification costs, and evaluates six selection scenarios. Deterministic profile tests verify cost switches and capacity refusal independent of CPU timing. A continuation-only 8-bit storage contract admits the packed mode and excludes both the 10-bit feature and 128-bit source representation; a seven-bit ceiling refuses among the offered future-complete modes (not a proof about every possible endpoint-specific continuation). Terminal support tests exhibit necessity witnesses and compare states agreeing only on the selected coordinates.
