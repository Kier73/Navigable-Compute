# NCR-016 — Symbolic induction without cold target formation

A follow-up discovered during NCR-015. All three learned majority pair-OR relations have exact short certificates that were already implicit in the original acquired majority relation. This motivates a direct proof search, not just memorizing cold-verified consequences.

Let r=1 XOR ab XOR ac XOR bc be the vanishing observation equation for majority(a,b,c)=1. Define g_ab=(1 XOR a)(1 XOR b). Every nonconstant term in r contains a or b, so g_ab*r=g_ab (Boolean multiplication is idempotent, and a(1 XOR a)=0). Since r=0 on the admitted fibre, g_ab=0, or a OR b=1. The same applies to the other pairs. Moreover g_ab XOR g_ac XOR g_bc=r: one of the three rules is algebraically redundant.

## Implementation

Vocabulary.train_symbolic iterates the same bounded proposal grammar as NCR-015. If a candidate is already resolved by existing admitted rewrite rules, skip it. Otherwise, for candidate q and b in {0,1}, set g=q XOR b, and test g*r=g against each available admitted rule r. The independent existing verifier checks the exact certificate g=XOR_{m in g} x^m*r. The resulting learned row is admitted only after that check. Previously derived rows may be used for subsequent derivations; certificates reference only earlier admitted rule indices at admission. No residual DAG is constructed during this induction. The input fibre admission and its verification remain paid, and packet restoration still requalifies every learned row by the cold exact path rather than trusting an archived proof.

The limits bound product attempts and emitted term visits, separately from the bounded per-proposal rewrite. The algorithm may miss any consequence requiring more than this one-rule product grammar and returns no completeness assertion. Rule search, candidate enumeration, independent verification and initial admission have actual wall cost. A stronger symbolic elimination or ideal basis may outperform this approach. The same context restrictions and in-process trust model as NCR-015 apply.

The test disables the actual cold query method while invoking symbolic induction; then re-enables it to check all learned facts independently. It verifies the two-rule vocabulary resolves all 48 held-out targets from NCR-015, rejects false constants on 48 shifted targets, checks the opposite observation and budget refusal, and restores the compressed packet. The demo measures both induction routes on the same admitted 128-bit fixture. The test family is deliberately structured.
