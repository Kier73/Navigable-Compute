# NCR-008 — Realized observer images and optimal packed coordinates

Continuation of [NCR-007](NCR-007.md), [NCR-006](NCR-006.md), and the [IFS translation discovery log](https://github.com/Kier73/In-Formation-Space/blob/main/reports/TRANSLATION_DISCOVERY_LOG.md). The experiment addresses the difference between minimum invariant linear feature dimension and minimum information-theoretic encoding of the actual observer quotient.

## Construction

For a source state x in GF(2)^n and admitted ANF feature basis q=(f_1,...,f_r), NCR-007 already proves q(T_a(x))=M_a q(x) and O(x)=Dq(x). Its least pullback-invariant span implies q(x)=q(y) iff all future stipulated observations agree.

Build the incidence graph of features and the source variables appearing in their ANF monomials. Each connected component C has a set of feature indices J_C and source support S_C. Supports of distinct components are disjoint. Construct local image V_C={q_J(x_S): x_S in GF(2)^|S|}. The full source domain is the Cartesian product of its independent variable assignments, so the image of q is exactly the Cartesian product of V_C (with feature indices scattered back into their original positions). This is an image over the entire declared Boolean domain, not a reachability claim from a particular initial state.

Therefore

    |im q| = product_C |V_C|
    b_min = ceil(log2 |im q|)

A mixed-radix rank of the sorted local images gives a bijection to integers [0, |im q|). No global Cartesian product is materialized. A packed transition is pack(M_a unpack(code)); the original checked linear representation remains available for far-time matrix powering. The packed representation reduces state capacity, not necessarily operator arithmetic cost.

For general coupled ANFs a large component can still require exponential enumeration. The producer refuses before exceeding its declared local work allowance, rather than asserting a smaller image. The charged cells count assignments times (features + monomials) per component, not all CPU operations or memory.

## Exact analytical fixture

64 independent lanes, each (x_i,y_i,x_i*y_i), yield 192 linearly independent features of 128 source bits. Each local image contains four values, so the global image contains 4^64 = 2^128 coordinates and its optimal packed representation is 128 bits. The producer uses 256 local assignments and 1,536 charged cells, versus 2^128 source assignments for direct exhaustive enumeration. The features include the two original bits per lane; this is compression of the feature representation, not compression below source width. This family is a standalone exact feature-map fixture, not a claim that the particular 192 features arise from a specified dynamical observer closure.

The native NCR-007 benchmark also computes the actual image of the original 128-bit nonlinear source's qualified basis, preserves its native two-action semantics, and checks a distant observation at 10^100+173. The runtime does not enumerate all native source states.

## Implementation and qualification

- `navigable_compute/realized_image.py`: local exact image construction, factor records, mixed-radix pack/unpack and native packed step.
- `verify_image`: independent local truth evaluation using sets of variables, checks exact feature partition, disjoint support, image equality and cost. The supplied basis and width are the verifier's inputs; the certificate is not a signature or independently self-authenticating wire packet.
- `tests/test_realized_image.py`: full-domain comparisons on 150 small random maps, exact 64-lane image, native NCR-007 action commutation and closed image, budget refusal, forged image/support/cost controls, constant and empty cases.
- `realized_image_demo.py`: reports cold construction, independent qualification, warm packing, optional full-source enumeration on small cases, and native Ground compilation and verification costs. The timing baseline is exhaustive image construction, not the fastest possible direct source execution; no comparison to all alternative algorithms is implied.

```sh
python -m unittest discover -s tests -p 'test_realized_image.py' -v
python realized_image_demo.py
```

Callers first verify NCR-007 source and feature Ground, then verify_image against that exact basis and source width. Pack/unpack and packed_step consume a trusted, previously verified immutable certificate. Do not treat a certificate received from an untrusted caller as admitted.
