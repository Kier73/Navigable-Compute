## Exact task

A checked NCR-010 parent represents a nonempty set F of initial coordinates. One unknown member x is drawn under an explicitly stipulated uniform prior; this is a scenario assumption, not observed frequencies. The task is to know the Boolean target polynomial T(x). An available probe a supplies the bit p_a(x) at declared positive cost c_a. The fallback is a direct target measurement at price f, available if the offered packet leaves T unresolved. All probes and the target are exact ANFs in the parent coordinate convention; after NCR-011 reordering, rename source equations into the selected coordinate system first.

For each packet S (including the empty packet; up to six offers, at most two simultaneous observations) and every possible bit vector b, form an NCR-011 persistent overlay F_b and its target-positive intersection G_b=F_b intersect {T=1}. Their checked counts are n_b and y_b. Zero-mass branches are contradictions if received. If y_b is 0 or n_b and n_b>0, the task is resolved without fallback; otherwise fallback is required. Sum n_b = N=|F|.

Three independent properties of the candidate:
- All-state unresolved pairs U=sum_b n_b(n_b-1)/2.
- Task-opposed unresolved pairs A=sum_b y_b(n_b-y_b).
- Fallback mass H=sum_b n_b*[0<y_b<n_b].

Geometry is priced explicitly. Let m_b be the number of new overlay nodes (not parent nodes and not the target proof), retained after acquisition. Let V_b be the sum of positive overlay-node visits over every address of F_b when embedding it in the old Ground. At positive overlay node r, V(r)=C(r)+V(low)+V(high), with V=0 for references into unchanged parent subtrees and for empty branches. This follows by partitioning address intervals. Shared suffixes are charged for every distinct prefix. The verifier separately propagates prefix multiplicities forward and sums multiplicity*C(r).

If k future address embeddings sample uniformly from the selected fibre (with replacement), the exact expected total charge of the specified execution policy is

    J(S) = sum(c_a) + [f*H + lambda*sum(n_b*m_b) + mu*k*sum(V_b)]/N.

Prices f, lambda and mu are caller-declared common cost units; k is a declared query count. The numerator is compared as an arbitrary-precision integer; ties prefer acquisition cost, packet size and lexical names. The empty packet is a baseline with no overlay or address charge. The policy's task remains the same for every candidate. The charge excludes the common old Ground and original source reconstruction; it counts only the stated address embedding workload, not all CPU instructions, latency, serialized bytes or network traffic.

## Preparation is paid

All branches, including impossible ones and the empty packet, are constructed before selection, using actual NCR-011 refine and verify_refinement. Target-positive proofs are separate intersections of the original parent with the packet and target. They are not retained overlay nodes in the hypothetical post-selection cost, but are paid during planning. Plan.prepared_nodes and prepared_work sum all constructed overlays and target proofs, including losing candidates. Wall timing includes repeated independent parent audits. Verification replays proof checks for all candidates; it does not trust scores or the selected offer. No claim of net speedup follows from the warm score. A production admission could retain the checked chosen branch proof and discard losing branch structures, but this implementation keeps the full plan for audit. Maximum 73 outcome branches (six offers, packets of up to two); each has two refinements. Per-refinement node/work budgets apply to every attempted proof. If any branch exceeds budget, exact optimization refuses rather than silently ignoring a potentially superior candidate. No arbitrary multi-step optimality claim.

## APIs

    from navigable_compute.intention_fibre import construct_fibre
    from navigable_compute.fibre_attention import Offer, Prices, plan_attention, select_outcome
    from navigable_compute.fibre_attention_verify import verify_attention

    f = construct_fibre(8, ())
    offers = (Offer("a", (1,), 1), Offer("b", (2,), 1))
    target, prices = (1,2), Prices(10)
    p = plan_attention(f, offers, target, prices, max_packet=2)
    assert verify_attention(f, offers, target, prices, p, max_packet=2)
    assert p.selected == ("a","b")
    o = select_outcome(p, (("a",1),("b",0)))
    assert o.inferred == 1
    assert o.overlay.rank(o.overlay.unrank(0)) == 0

select_outcome consumes a previously checked immutable plan and exact selected names and values. It rejects impossible outcomes and returns inferred=None for mixed target branches; it never guesses the hidden state. A raw supplied bit is a mathematical declaration, not an authenticated measurement. For a real receiver, reuse VL-I TDL-003/004/005/006 and E-CPU receiver-owned typed requests with VGI finalized AUTHORIZED evidence. That adapter must bind the source epoch, parent Ground identity, selected polynomial and outcome, rather than trusting the offer label. Physical integration is a separate next implementation.

## Discriminating fixtures

- Complementarity: independent bits a,b, target a XOR b. Individual probes leave fallback mass unchanged and cannot beat no probe at positive cost. Together they resolve the task for acquisition cost 2 rather than fallback 10.
- Information versus task: a balanced irrelevant bit separates more state pairs than the biased quadratic gate x14*x15, but the latter alone resolves that target. Compare both ambiguity metrics with cost; no assumption that generic information gain equals utility.
- Geometry versus information: target OR of the highest and lowest bits, equally priced raw offers. Their state and task pair counts and fallback mass are identical. On a free 16-bit parent the highest-bit overlay has one node and one embedding visit per address; the lowest-bit overlay has 16 of each. At zero geometry price lexical tie selects low; positive geometry prices select high. On the free 128-bit fixture the gap is 1 versus 128; preparation still pays every candidate.
- A connected 128-bit path uses the prior nonlinear adjacent-exclusion Ground. The demo reports exact candidate-specific prices and observed preparation/audit time, without assuming independent bits in that domain.
- Seeded exhaustive source enumeration verifies conditional counts, target truth, rank/unrank and visit mass on small mixed ANFs. Tampering, impossible observations, budget exhaustion and empty parent controls refuse.
