# NCS-001 — Task-generated execution algebra

**November 20, 2026.** Executable finite mathematical research, independent of RH/GRH correctness. This is **not** a universal self-hosted virtual machine.

## Research question

Can an intention determine its own *instruction vocabulary*, not merely select a state within a pre-existing CPU? Can the resulting programs be interpreted as operations of the same derived mathematical structure, without supplying an external ISA?

NCI-001 already constructs shortest-progress, symmetry-equivariant processor laws from safety, goal, symmetry, geometry, observable labels and a movement bound. NCS-001 takes that constructed family, **restricts it to the qualified states** `Q={s:rank(s)>=0}`, and selects the first `min(generator_limit, law_count)` canonical law coordinates. These become the generators `G` of a finite transformation monoid:

`M = <G, identity_Q>`, with multiplication `a*b = a after b` and action `eval(a,s)=a(s)`.

Distinct finite transformations become endogenous semantic **opcodes**. Programs are words in the generated `G` vocabulary; each opcode is assigned a canonical shortest-then-lexicographic word. The complete multiplication table defines instruction composition. A program can be executed by applying its resulting operation on the derived state space. Repeated programs use exact binary exponentiation *in the derived monoid*, so logarithmic many products suffice after full construction.

The opcode vocabulary is not supplied by the user, but the *mathematical meta-interpreter and enumeration algorithm are still implemented in Python*. Algebraic self-contained semantics does not imply self-hosted interpreter code, computational independence from physical hardware, or universal program synthesis.

## Deterministic fixture

A 5×5 quarter-turn invariant world gives 16 canonical shortest-progress laws. Closing those 16 transformations yields 29 different semantic opcodes, including identity. Order matters: `g0;g1` and `g1;g0` yield different effects. Repeating a six-instruction program `10^100+173` times takes **442 monoid multiplications** and produces the goal state after convergence. The closure cost, all finite maps and whole multiplication table are counted separately, not hidden in the time-jump claim.

Small controls: a 3×3 source yields four monoid elements; an all-goal Ground has only identity. An operator-budget overflow refuses instead of falsely labeling a partial closure complete. No speed comparison with optimized native compilation, SAT/SMT solvers or real physical processor execution is claimed.

## Independent verification

- `self_verify.py` independently verifies the NCI Ground; reconstructs generator maps from mixed-radix law coordinates without using the producer's law-selection method; constructs the closure as a **set**; checks every source instruction word; verifies canonical shortlex descriptions; and recomputes every multiplication-table entry directly by functional composition.
- `self_wire.py` transports the complete finite processor capsule in bounded canonical JSON, including exact semantics. The receiver must supply the **trusted external invariant description** and verifies the entire structure before it can be interpreted. Semantic forgery is rejected even when an attacker recomputes the untrusted digest. A digest is neither a digital signature nor E-CPU authority.
- `tests/test_self_space.py` checks every internal opcode on every input state, exhaustive small source machines, 100 randomly generated word traces against direct NCI source transitions, high-coordinate exponentiation, noncommutativity, malformed or forged capsules and resource-budget refusal.

## The significant next step: a genuine reflective processor

NCS-001 gives a closed algebra **M acting on Q**. To move from semantic closure to the fuller self-interpretation suggested by the research goal, construct a separate *reflective Ground* on `M x Q` with an evaluator operator `Eval(m,s)=(m,m(s))`, prove that it is a legal transformation in the new Ground, and express its interpreter as a program **in its own derived language**. A rigorous self-hosting claim requires a commuting semantics diagram and an independently tested recursion/evaluation contract. The finite monoid alone is generally not expressive enough to contain a universal interpreter.

Further: derive the geometry and even the representation `Q` from a raw mathematical problem or application-state specification rather than a supplied grid; use CEGIS, counterexamples, symbolic semantics, equality saturation and independent model-checking. Connect the resulting *qualified mathematical* capsule to VGI's interpretation contracts and E-CPU Virtual Processor's persistent, authenticated observer-host identity. Physical realization remains a separate witness.

### Relevant mathematical prior art

- [Futamura projections](https://www.jstage.jst.go.jp/article/jssst/21/5/21_5_343/_article/-char/en): specialization can transform an interpreter into a compiled program.
- [Kleene recursion theorem](https://plato.stanford.edu/entries/recursive-functions/): self-reference is mathematically possible for universal programming systems, without implying free computation.
- [Equality saturation](https://www.cs.cornell.edu/~ross/publications/eqsat/): symbolic representation of many equivalent programs. NCS-001 instead enumerates a **bounded exact semantic closure** and merges identical finite functions, not an e-graph optimizer.
