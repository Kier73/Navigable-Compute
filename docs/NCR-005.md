# NCR-005 — Observer-native coordinates from an intention-relative language

Research status: exact bounded finite mathematics, November 21, 2026. NCR-005 composes invariant-derived NCI-001 source generators with NCR-004's observer quotient and instruction monoid, then constructs an exact coordinate algebra. This is not a physical host, unobserved environmental law, universal minimum-dimension theorem, or permission to execute external effects.

## Question and pipeline

Can an intention determine the useful states, then the language, then the mathematical coordinates in which that language runs? The implementation reuses the existing independent NCR-004 verifier, never enumerates the original source transformation monoid, and chooses between:

1. A diagonal character algebra when the observer quotient forms a transitive elementary abelian two-group.
2. An exact sparse one-hot representation for arbitrary finite deterministic quotient actions, including nonbijective resets and noncommuting transformations.

The end-to-end path is: NCI-001 invariants or declared generator tables -> NCR-004 reachable Moore quotient and context-stable program monoid -> NCR-005 native coordinate constructor -> independent algebra verifier -> logarithmic-power coordinate query -> independently verified observation and canonical transport packet.

## Character algebra and restricted minimality

Let Q contain q=2^r observer-equivalent state classes. If its primitive quotient maps are permutations, involutions, mutually commuting, and jointly transitive, their faithful action on Q is regular and isomorphic to H=(Z/2Z)^r. NCR-005 derives a canonical basis in source generator order by exact orbit doubling, assigning each state a bitmask b and each instruction an XOR shift delta.

Over the prime field F_257:

\[
z_j(b)=(-1)^{b_j}\pmod {257},\qquad
D_\delta=\operatorname{diag}((-1)^{\delta_1},\ldots,(-1)^{\delta_r}).
\]

The operation law D_delta z(b)=z(b XOR delta) is checked against **every** quotient state and operation. Arbitrary categorical observer labels are independently reconstructed by a finite-field Walsh expansion:

\[
f(z)=\sum_{S\subseteq[r]}\widehat f_S\prod_{j\in S}z_j,\qquad
\widehat f_S=2^{-r}\sum_b f(b)(-1)^{\sum_{j\in S}b_j}\pmod {257}.
\]

Dimension r is minimal **among faithful affine representations of this full elementary abelian group over an odd-characteristic field**. A finite group action admits a common affine fixed point by averaging because its order is invertible; translation reduces it to a linear representation. The commuting involutions simultaneously diagonalize with entries ±1, so d coordinates represent at most 2^d distinct group elements. Faithfulness forces 2^r<=2^d and therefore d>=r. This does not establish general minimum dimension under nonlinear encodings or other operator families.

## Exact one-hot fallback

For every other supported finite quotient use basis vectors e_i in F_257^q. Operator a is stored as a column-sparse map M_a e_i=e_{a(i)}; outputs are exact finite-field linear readouts. This remains exact for resets and noncommuting monoids, but makes no optimality claim. The default representation dimension budget is 64; oversized representations refuse.

## Exact time navigation

Compose a source generator word into an NCR-004 opcode, then power its native operator at any nonnegative integer coordinate of at most 4096 bits. Both native modes take O(log t) operator compositions for fixed representation, excluding source-law discovery, quotient closure, algebra construction, verification and output materialization.

The independent NCR-005 verifier never calls the representation constructor, its readout method or its navigator. It checks all native source-to-target operator intertwinings; validates the character basis or one-hot matrix form; independently evaluates the output; reconstructs the source-word transformation from primitive quotient generators; and computes a distant result by a separate full finite state-map binary-power oracle. A recomputed SHA-256 alone is not accepted as mathematical authority.

Canonical packets reuse NCR-004's strict source and language decoder, rejecting duplicate keys, unknown fields, changed dynamics/observations, malformed arrays, rehashed semantic forgeries and unsupported results. These are integrity and mathematical proof objects, **not** signed external evidence or E-CPU Hypervisor grants.

## Most important next question

The next breakthrough would derive an intention-specific symbolic quotient and faithful character representation **before** source-state enumeration, using exact symmetry declarations, SAT/BDD/SMT or algebraic certificates, with independently checkable correctness and explicit budget refusal. Arbitrary observer readouts can still require 2^r Walsh coefficients despite r-dimensional state evolution.

Subsequent integration with VGI and E-CPU must separately admit live observations, qualify physical operator semantics, authorize execution, and measure transport, recovery and total cost. The current mathematical processor does not imply independent physical realization.
