NCR-010 constructs a counted residual DAG in source integer order. NCR-011 keeps that implementation and adds two distinct transformations: source-coordinate permutation before formation and an immutable overlay after formation. It studies [IFS BENCH-01G](https://github.com/Kier73/In-Formation-Space/blob/db4a29de951d2ccd5d87dc8c5008d16b340d8bcb/experiments/pnp-ground-navigation/benchmarks/bench01_separator.py) for source incidence conditioning, [IFS CIG-025](https://github.com/Kier73/In-Formation-Space/blob/db4a29de951d2ccd5d87dc8c5008d16b340d8bcb/experiments/pnp-ground-navigation/cut_intention/CIG-025.md) for independently checked rank/select, and [VL-I TDL-002](https://github.com/Kier73/VL-I/blob/c2052939a00ea16b052b1b37cf2e517686345ce0/docs/MINIMAL_REFINEMENT_TDL002.md) for preservation of an old coordinate during observer succession. ## Coordinate choice

Construct the primal incidence graph: two source variables are adjacent whenever they appear anywhere in the same ANF equation (not merely in the same monomial). For a proposed traversal, the frontier is the unassigned variables adjacent to assigned ones. Greedily select the next variable minimizing the new frontier, favoring its existing neighbors on ties. This is a bounded structural heuristic, not an optimal ordering or a proof of low residual width. The traversal determines a source permutation P into NCR-010's high-to-low branch order.

For every equation p, rename every monomial through P. The identity p(x)=P(p)(P(x)) follows from the bijection of variable indices, hence the solution sets and cardinalities are preserved. Ordered rank and unrank use the renamed coordinate and inverse permutation; ordinal identity is explicitly order-dependent. The independent verifier checks the source permutation using a separate bit translation and then invokes NCR-010's independent residual checker.

choose_ordered compares at most the frontier proposal and original numeric ordering under identical per-candidate node/work budgets. The winner minimizes stored node count, then charged residual work, then permutation. Each candidate, including a refused one, records elapsed time including its qualification when completed. Planning is separately timed. The portfolio may spend twice the configured per-attempt formation budget and pays independent checking as well. A budget refusal is UNKNOWN, not an empty solution set. If both fail, no candidate is returned.

## Observation succession without rebuilding the parent

Let a previously checked parent DAG represent F, and let E be newly asserted ANF equations. Form an overlay whose key is (parent node p, residual E'). For each branch, follow the parent edge and substitute only the new equations. An empty parent subtree or contradictory new residual yields zero. If all new equations disappear, reuse the old subtree by a negative reference -p; no further overlay nodes or residual substitutions are needed. The count is the sum of the two disjoint child counts. Induction proves that the overlay represents F intersect E, including every satisfying assignment exactly once.

The old and new orders are identical. At an overlay high edge, the old ordinal offset advances by the **parent** low-child count; the new ordinal is reduced by the **overlay** low-child count. When the overlay references an unchanged subtree, the remaining relative ordinals agree. Therefore parent_address(j) is the exact monotone injection of new ordinals into old ordinals, and refined_address(k) is its partial inverse. Excluded old ordinals are refused. Mapping needs at most the source width in node visits and need not decode a source state. A later consumer can realize the original source via OrderedFibre.unrank(parent_address(j)).

The checker independently substitutes only new equations, checks product edges against the admitted parent, verifies every reused subtree identity and count recurrence, and rejects unreachable or duplicate overlay nodes. Both formation and checking currently re-audit the full immutable parent; benchmark their cost rather than treating parent qualification as free. An overlay retains a parent reference, not a standalone portable packet; no external observation authority or source epoch is conferred. Explicit node/work limits bound new residual formation, not total wall time. Dense equations or poor orders can still have exponential cost.
