# NCR-007 — Invariant-generated nonlinear processors with exact observer Koopman Grounds

**Status:** bounded exact mathematical construction and adversarial verification. **Date:** November 21, 2026. This is a fully stated synthetic Boolean source law family, not discovery of an unknown external process, a general nonlinear compression guarantee, neural model execution, or physical E-CPU admission.

## Research question

NCR-006 produced an exact future-observer quotient of a finite binary *affine* source without source-state enumeration. Could the original source laws instead be **generated from invariants**, allow genuine nonlinearity, and still admit **constructed** exact observer-native execution coordinates without visiting the original source states?

**Result for a specified family:** yes. NCR-007 generates Boolean polynomial transformation laws from causal rank, allowed dependency topology, symmetry equivariance, degree and protected-register conservation. The resulting generally nonlinear transformations are then represented in a *least pullback-invariant linear span of observer functions*. Where the observable-function span fits the explicit budget, its finite-dimensional linear operations preserve every future observation of the stipulated nonlinear source.

The finite Koopman representation idea is established in the mathematical literature; NCR-007's contribution is the **end-to-end constructive integration with invariant-generated Boolean laws**, explicitly source-bound exact identity checking, refusing budgets, and independent small-state equivalence oracles. See [Koopman Representation for Boolean Networks (2023)](https://www.sciencedirect.com/science/article/pii/S2405896323007383) and [Koopman Invariant Subspaces and Finite Linear Representations of Nonlinear Dynamical Systems for Control (2016)](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0150171).

## 1. Generate a nonlinear processor without a transition table

The state is a bit vector x in F_2^n, 2<=n<=128. A declared invariant description contains:

- An integer tier t(i) for each bit: -1 for a conserved register, or a nonnegative rank for an active (eventually drained) bit.
- A directed allowed-input graph P(i), such that a non-protected output bit i may depend **only** on active input bits j with t(j)>t(i).
- A maximum source polynomial degree d in {1,2,3}.
- A permutation g of bits, respecting ranks and the allowed-input graph, which source transformations must commute with.
- One or more exact Boolean observer functions, encoded as squarefree algebraic normal forms (ANFs). Observer outputs need not be symmetry-invariant.

For active bit i, the allowed monomials are all products of 1..d different input bits drawn from P(i). For protected bit i, the output is *exactly* x_i. There are no active constant terms or lower/same-tier dependencies.

The symmetry acts on coefficient slots (output index, source-monomial mask). The constructor enumerates only these **symbolic coefficient-template orbits**, not source states or the source operator monoid. One independent Boolean choice is admitted per orbit. Choosing a nonnegative integer law coordinate selects a member of the resulting finite family, with cardinality 2^k for k coefficient orbits. Multiple generator coordinates construct a source action alphabet; no arbitrary transition table is supplied.

Every generated operator has form

\[
T_a(x)_i =
\begin{cases}
x_i, &t(i)=-1,\\
\bigoplus_{m\in\mathcal M_i}c_{a,i,m}\prod_{j\in m} x_j, &t(i)\geq 0.
\end{cases}
\]

The coefficient equality over symmetry orbits implies T_a g = g T_a for **every** source state. Protected bits are conserved identically. The ranked dependency property proves that, for h=1+max_i t(i), **every word of at least h generators sends all active bits to zero**, with protected bits unchanged. This follows by induction from the highest tier downward, and holds without enumerating 2^n states. Nonlinearities can be authentic quadratic AND monomials even though the law family is selected by binary coordinates.

This source design intentionally only generates *causally draining finite processes*. It does not describe recurrent nonlinear dynamics, cross-tier feedback, general physical control, or an unrestricted self-interpreter.

## 2. Observer-sufficient algebraic normal forms

Let ANF functions be elements of the Boolean polynomial ring

\[
\mathcal B_n=\mathbb F_2[x_0,\ldots,x_{n-1}]/(x_i^2-x_i).
\]

Represent a polynomial by an XOR set of distinct variable-mask monomials; multiplication ORs monomial masks and cancels even duplicates. This gives a **canonical polynomial function on the full 2^n Boolean domain**, without enumerating domain points. Importantly, algebraic normal forms are unique as Boolean functions.

For each generated source law T_a, define its pullback on an observable polynomial f:

\[
K_a f = f\circ T_a.
\]

Given the observer output bits o_1,...,o_m, construct the **least** finite-dimensional GF(2)-linear subspace

\[
W = \operatorname{span}_{\mathbb F_2}
\{K_w o_j:\ w\in A^*,\ 1\leq j\leq m\}.
\]

A bounded exact producer starts from observer ANFs and repeatedly pulls back each newly independent feature through **every** generator; new features are admitted only if an exact high-pivot polynomial elimination finds linear independence. No interpolations, sampling, floating-point projection or approximate truncation are used. If the number of independent functions or intermediate ANF products exceeds the declared limits, the constructor refuses.

A basis f_1,...,f_r of W constructs the observer-relative coordinate:

\[
q(x)=(f_1(x),\ldots,f_r(x))\in\mathbb F_2^r.
\]

For each generated nonlinear source action there exists an exact matrix M_a over F_2 such that

\[
q(T_a(x))=M_a q(x)\quad\text{for ALL }x\in\mathbb F_2^n.
\]

The observation decoder is another exact GF(2) matrix D satisfying O(x)=Dq(x).

**All-future distinction theorem.** Two source states have the same q coordinate if and only if they have the same observation under every finite action word: equality of all f_j is equivalent to equality of their span W, which is precisely the span of all future observer pullbacks. Thus q represents exactly the observer's future-equivalence classes as an **image** in F_2^r.

**Important nuance:** the image q(F_2^n) need not contain all 2^r bit vectors. We do **not** claim that 2^r observer states are realized, nor that r is the minimum bit-width under arbitrary nonlinear encodings. The proven minimality is the *linear dimension of the invariant Boolean-function span*, and the q-equivalence is exact. A smaller nonlinear encoding of the same equivalence classes may exist.

The linear matrix M_a is not a linearization of the original source state: it is the exact pullback operator restricted to the observer's function space. The original nonlinear source remains nonlinear. This is the familiar finite Koopman viewpoint, made constructive for a source generated from invariants.

## 3. Independent checking and far-coordinate navigation

The source-family verifier **reconstructs the monomial templates and symmetry coefficient orbits independently** and checks every emitted polynomial coefficient against the selected law coordinate and protected/ranked invariants.

The feature-ground verifier has a separate low-pivot polynomial elimination engine and its own ANF substitution algorithm. It rebuilds the future-observer function span, verifies equality of the proposed feature span, checks every symbolic identity f_j(T_a(x)) = sum_k (M_a)_{jk} f_k(x) as ANF, and reconstructs all observer outputs as ANF. These identities hold across the **full source state space** without sampling.

Navigation composes the generated linear operators for a source-action word and powers the result by binary exponentiation, with O(log N) matrix compositions for N repetitions. An independent audit does not call the feature navigator: it evaluates the *original nonlinear source equations*. The ranked-source theorem permits a bounded exact shortcut: after h or more primitive actions all active bits equal zero, and all protected bits remain unchanged. Thus any far-coordinate result is checked directly against the source, not an unverified extrapolation.

Canonical byte packets include all source-invariant declarations, chosen law coordinates, derived source polynomial rows, observer features, generated matrix rows, decoder, and results. Duplicate JSON keys, unknown fields, changed provenance, malformed decimal bit masks and even rehashed semantic forgeries are refused. SHA-256 is an integrity reference, not a signature, permission, or external sensor measurement.

## 4. Reproducible experiment

    python -m unittest discover -s tests -p 'test_nonlinear_koopman.py' -v
    python -m unittest discover -s tests -v
    python nonlinear_koopman_demo.py

The main demonstration uses a **128-bit** source with a rank-layered family of eight independent 8-bit active lanes plus 64 protected bits, 2 noncommuting candidate generator coordinates, and a two-bit observer (nonlinear lane-zero output and one conserved register).

No source states or source transformation monoid are enumerated. The generator family has many independent nonlinear coefficient choices even though the observer only requires features in one active lane and the protected readout. The first generator includes the quadratic transformation x'_0=x_1 x_2; its next layers include x'_1=x_3, x'_2=x_4, x'_3=x_6, x'_4=x_7. Consequently the observer sees a chain of **nonlinear source features**:

\[
x_0\ \mapsto\ x_1x_2\ \mapsto\ x_3x_4\ \mapsto\ x_6x_7\ \mapsto\ 0.
\]

The protected observer remains visible. This trajectory is illustrative; correctness is proved algebraically for **all** source states and all generated action words, not only that sample.

A requested logical coordinate N=10^100+173 is evaluated through the generated feature matrices. The independent checker reconstructs the result from the original nonlinear law and its proved finite convergence horizon. Output packet construction and decoding invoke the independent mathematical checks.

The negative control is a rank-decreasing source shift whose single present observable depends on **14 distinct future functions**. An eight-feature budget refuses it; the full 14-feature solution is constructible. Exhaustive small-state pair-distinguishability tests independently check future-equivalence of source states against the derived q values across varied nonlinear law coordinates.

Other tests exercise nontrivial equivariance, conservation, algebraically verified quadratic nonlinearity, tampered/rehashed source or ground claims, canonical bytes, invalid graph/symmetry declarations, constant observer (zero-feature Ground), and agreement with NCR-006 on an affine subfamily.

## 5. What is genuinely advanced, and what remains

**Advanced:** A specific computational environment defined only by invariant requirements (ranks, permitted causal topology, conservation, symmetry, degree and target observations) can generate a family of **nonlinear** source processors, then construct its own **exact observer-sufficient linear computational language**, without state enumeration. The mathematical proof checks a whole operator family and all future observations. Nonlinearity is handled by selecting functions suited to the intention, rather than expanding the original execution into a conventional full-state virtual machine.

**Still in development:**

1. The causal-rank condition precludes feedback and persistent nonlinear recurrence. General feedback systems can require an exponentially large invariant feature span; exact construction must use more advanced symbolic algebras or refuse.
2. Both the polynomial-template orbit count and exact ANF pullback expansion can grow combinatorially. Construction has explicit work and feature budgets; no general polynomial-time claim is made.
3. Source topology, symmetry and observer functions are **supplied mathematical declarations**, not learned from external physical data. Selecting a law coordinate chooses among admissible constructions; the experiment does not assert an independently observed natural law.
4. Linear-feature dimension r is not automatically equal to the information-theoretic minimum number of state bits. Future-equivalence is exact; the quotient image cardinality may be smaller than 2^r.
5. True cross-repository physical execution still requires VGI source/evidence admission and E-CPU Hypervisor-controlled receiver ownership, plus transport/cold-start/recovery cost accounting.

The discriminating next research task is to replace the supplied causal/topological invariants with independently evidenced constraints, then **synthesize the minimal proof-sufficient nonlinear processor** while maintaining a certified observer projection and native host realization.
