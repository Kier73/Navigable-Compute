# CGR-002 — Source-witnessed Ground admission into NCR-004

## Question

Can finite, source-reported transitions construct a native computational language without supplying a transition table to the language constructor?

The implementation uses existing NCR-004: its preclosure observer-language constructor, independent verifier, and portable wire checker. It does not introduce an alternate architecture, transport, quorum, fence, or proof engine.

## Formal contract

An epoch E = (source, context, S, A, S0, W) carries an ordered sequence of witnessed source transitions (before, action, after, before-output, after-output). Exact canonical source bytes determine the epoch source SHA-256. Receivers must receive the expected head **out of band**; a digest cannot authenticate an observation.

Qualified reachable support R consists of states reachable from S0 through supplied witness edges. All state outputs on R must be consistent, and every state/action pair on R must have a witnessed successor inside R. Missing evidence yields a concrete IncompleteSource query rather than an invented law. Conflicting transitions or labels fail as a nonstationary/contradictory epoch.

Once the witness graph is closed on R, it becomes a native GeneratorObservation and passes through original construct_preclosure_language, verify_preclosure_language, encode_preclosure, and decode_preclosure functions.

The native mathematical theorem is equality of readouts for all finite action words in the qualified support. Large repeated word counts use logarithmic quotient-map powering after construction; source acquisition and proof-building costs are not accelerated by this fact.

## APIs and native tests

The module navigable_compute.observed_ground introduces:
- TransitionObservation and ObservedEpoch: exact source-reported records, canonical identities.
- admit_observed_epoch: source-pinned admission and reuse of native NCR-004 mathematical construction and proof.
- IncompleteSource.missing: independently queryable unknown state/action obligations.
- SourceAdmission: actual NCR-004 Ground language and native wire bytes.
- navigate_observed: recheck native qualification and render large time coordinate.

The tests exercise the actual NCR-004 code with a six-state/two-class source and 10^80+19 coordinate, missing transition, altered epoch, conflicting evidence, tampered wire, and unreachable-state distinction.

## Explicit scope

This establishes finite deterministic stationary **mathematical** source-relative behavior, not signed sensor authority, model-domain generality, physical effect rights, neural computation, external-host continuity, or independent WAN failure domains.
